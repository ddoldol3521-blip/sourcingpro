========================================
  초보용 — 코드는 안 고쳐도 됩니다
========================================

당신이 할 일은 "코드 수정"이 아닙니다.
브라우저에서 버튼만 누르거나, GitHub에 파일만 올리면 됩니다.


■ 사이트만 쓰고 싶을 때 (코드 0)
--------------------------------
1. 인터넷 주소로 들어간다. (GitHub Pages 주소)
2. "엑셀 파일 선택" 누른다.
3. 프리셋 탭으로 조건 나눈다.
4. "필터 적용" → "필터 결과 엑셀 다운로드"

끝. HTML/JS 열 필요 없음.


■ GitHub를 처음부터 다시 하고 싶을 때 (코드 0)
--------------------------------
1. GitHub에서 새 저장소 하나 만든다. (이름 아무거나)
2. PC에서 이 폴더 연다:

   새 폴더 (2) \ sellar-filter \ 올리기-이폴더만-GitHub

3. 그 안에 있는 것 "전부" 선택한다.
   (index.html, app.js, styles.css, .github 폴더, txt 파일)

4. GitHub 저장소 → "uploading an existing file" 또는
   Add file → Upload files

5. 끌어다 놓기 → Commit changes

6. Settings → Pages → Deploy from a branch
   → Branch: main, 폴더: / (root) → Save

7. 1~2분 기다린 뒤 주소로 들어간다:

   https://내아이디.github.io/저장소이름/

※ "내아이디" "저장소이름"은 본인 것으로 바꾼다.


■ 프리셋만 백업하고 싶을 때
--------------------------------
사이트에서 "프리셋보내기 (.json)" → 파일 저장.
다른 날 "프리셋 가져오기"로 그 파일 선택.

코드 수정 없음.


■ 막히면
--------------------------------
코드 고치지 말고, 화면 캡처를 아는 사람에게
"여기까지 했다"고 보여주면 된다.
